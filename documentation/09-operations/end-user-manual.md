## Tujuan dan Ketersediaan

Panduan penggunaan tingkat awal mengikuti flow dan module capability MTS. UI final belum dibangun, sehingga label/menu/screenshot dan prosedur langkah demi-langkah belum dapat dikonfirmasi. Pengguna hanya melihat data/aksi yang diotorisasi.

## Navigasi Umum

Masuk melalui halaman autentikasi; setelah login gunakan menu modul, dashboard, breadcrumb, search, notification center dan user menu sesuai hak akses. Jika menu/record tidak muncul, akses dapat dibatasi oleh role atau data scope; hubungi administrator, jangan mencoba memakai URL langsung.

## Prinsip Penggunaan

- Isi formulir sesuai validasi; baca error sebelum mengirim ulang.
- Periksa detail sebelum menjalankan aksi transaksi, approval, posting, payment, stock transfer, return/refund atau closing.
- Status queued/pending berarti proses belum tentu selesai; periksa status dan jangan mengulang transaksi finansial tanpa panduan.
- Data yang sudah diposting tidak diedit langsung; gunakan prosedur reversal/adjustment yang diizinkan.
- Laporkan kendala dengan waktu, modul, request/reference ID bila ditampilkan; jangan mengirim password, token, atau data sensitif lewat kanal dukungan.

## Module Guides Pending UI Confirmation

Organization/Core, HRM, Finance, CRM, Sales, Project, Collaboration, Inventory, POS, LMS, Analytics dan System Administration akan memiliki langkah sesuai fitur release, role, workflow dan kebijakan yang disetujui. Capabilities di MTS bukan jaminan semua fitur aktif pada versi awal.
